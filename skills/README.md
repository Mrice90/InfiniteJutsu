# Claude skills for Matt's projects

Procedures Claude has repeated while building **Infinite Conquest 3D** with Matt and the AI team. Each folder holds one `SKILL.md`. Read the matching one before doing that job again.

| Skill | Use it when |
| --- | --- |
| [blender-headless-cloud](blender-headless-cloud/SKILL.md) | Running any Blender job in the cloud container |
| [glb-decimate](glb-decimate/SKILL.md) | Slimming heavy Meshy models to a triangle budget |
| [rig-combat-clips](rig-combat-clips/SKILL.md) | Rigging characters and baking idle/walk/attack/hit/death/summon clips |
| [kitbash-structures](kitbash-structures/SKILL.md) | Building structure models procedurally without Meshy |
| [meshy-model-batch](meshy-model-batch/SKILL.md) | Generating new unit models in Meshy from card art |
| [elevenlabs-sfx-library](elevenlabs-sfx-library/SKILL.md) | Making card and UI sound effects at scale |
| [elevenlabs-music](elevenlabs-music/SKILL.md) | Making menu, battle and stinger music |
| [unity-build-remote](unity-build-remote/SKILL.md) | Importing, checking and building the Unity game on Matt's laptop |
| [sprint-board-claim](sprint-board-claim/SKILL.md) | Claiming or releasing work on the local SPRINT_LOG board |
| [rules-soak-test](rules-soak-test/SKILL.md) | Stress-testing the rules engine with bot matches |
| [ranked-referee](ranked-referee/SKILL.md) | Online ranked play, relay and referee |
| [launch-kit](launch-kit/SKILL.md) | Store page, press kit, pricing, legal drafts |

Before 2026-10-18 none of these were saved as skills; the procedures lived in project memory notes and in scripts on 3DTuba branches. This folder is the first written set.
